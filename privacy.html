Privacy policy

Last updated: 2026-10-31

"Kartik outreach tools" is a personal tool. Its only user is its owner, Kartik Mehra. It is not offered to anyone else.

What it accesses

With the owner's permission, the tool uses Google's Gmail API to:

  • read messages in the owner's own Gmail account, to see replies to emails he sent, and
  • create and send emails from the owner's own Gmail account.

How the data is used

Data is used only to run the owner's own email outreach: sending his emails and keeping track of replies. It is stored only on computers and services the owner controls. The owner uses an AI assistant (Anthropic's Claude) to help draft emails and read replies, so message text may be processed by that service on the owner's behalf.

Sharing

No data is sold, shared with third parties, or used for advertising. No data is used to train general-purpose AI models.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the tool's access at any time at myaccount.google.com/permissions.
